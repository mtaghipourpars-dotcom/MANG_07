# تمرین پنج تصمیم مدیرعامل

از بانک تازه استفاده کنید. زمان‌ها نسبت به لحظه مراجعه آموزشی هستند و داده واقعی نیستند.

```sh
python scenario-lab/run.py --db executive.sqlite
python scenario-lab/executive.py --db executive.sqlite --report executive.json
python -m unittest discover -s scenario-lab -p 'test*.py'
```

| پرسش | مسیر ردیابی |
|---|---|
| قول ۲۴/۷۲ ساعت | promises ← executive_promise و executive_prerequisite ← نوبت فعال و شاهد |
| اختیار من | governance.ceo_queue ← نقش، دامنه اختیار، مهلت و ارجاع |
| سفارش تازه | order_conflict ← portfolio_option، portfolio_decision، portfolio_reservation_attempt و portfolio_reservation_conflict |
| امکان پرداخت | finance ← سند هزینه، اردر، WBS، دوره، خط مبنا، جریان وجه و مهلت |
| از آخرین مراجعه | governance ← کارت دارای نسخه مصوب، شواهد نتیجه و ریسک باقی‌مانده، سوابق و دستور دیروز |

پرونده EXEC-FIN-01 کلید مشترک مشاهده سناریوی آموزشی است. پیش‌نمایش، مصوبه و رزرو مستقل‌اند. ایستگاه FAT-01 با بازه نیمه‌باز سنجیده می‌شود. آزمون هم‌زمانی از دو اتصال SQLite استفاده می‌کند. مدل مالی دو شاخه تأخیر موازی را پیش از برآورد یک مرحله وصول ترکیب می‌کند. رسید واقعی، اثر زمان وصول، هزینه ساخت و ظرفیت آزادشده در نما جدا هستند. نقش‌ها و اختیارها الگوی دمو هستند؛ احراز هویت سازمانی و اتصال واقعی SAP در پایلوت تعیین می‌شوند. سناریوهای مدیرعامل در همان فایل SQLite و جداول مستقل ذخیره می‌شوند. ماتریس قبلی بدون تغییر محاسباتی بازتولید می‌شود. شواهد این گام محدود به سناریوهای اجرایی این بسته است.
