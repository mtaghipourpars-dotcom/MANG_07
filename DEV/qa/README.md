# آزمون و پذیرش نسخهٔ دموی جامع

منشأ داده، بانک SQLite نسخهٔ ۱ ساخته‌شده از ورودی‌های موجود مخزن است. آزمون‌ها به نمونه‌های همین بانک ارجاع می‌دهند. ثبت‌های آزمون در نشست و بانک کاری موقت انجام می‌شوند. اجرای این آزمون‌ها به معنی تأیید دادهٔ عملیاتی یا هویت سازمانی نیست.

## اجرای مرحله‌ای

۱. با `node DEV/validate-spec.mjs` قراردادهای ماشین را کنترل کنید.
۲. با `python3 -m unittest discover -s scenario-lab -p 'test_*.py'` پایداری قرارداد ساخت بانک، یکپارچگی و تعارض ظرفیت را بررسی کنید.
۳. بانک آزمایشی را با `python3 scenario-lab/build_bank.py --db /tmp/pvpt-total-demo-qa.sqlite` بسازید. برای هر بازتولید مسیر تازه انتخاب کنید.
۴. پس از اجرای `npm install` و `npx playwright install chromium` مجموعه را با `PVPT_TOTAL_DEMO_DB=/tmp/pvpt-total-demo-qa.sqlite npm test` اجرا کنید. برای باینری موجود Chromium می‌توان `PVPT_CHROMIUM` را نیز تنظیم کرد.
۵. برای اجرای انتخابی، مسیر `tests/total-system.spec.js` را پس از `npm run test:demo --` اضافه کنید.
۶. گزارش JSON و آثار شکست را از اجرای Actions متناظر با همان کامیت در شاخهٔ `demo/total-system` بررسی کنید.

| آزمون | معیار ماشینی پذیرش |
|---|---|
| بانک سناریو | ۴۳٬۲۰۰ سناریو و ۷۵ مرجع. فیلتر دقیق و صفحه‌بندی پایدار. پیوند رویداد و اثر همراه با نمایش مقدار نامشخص. |
| شواهد مدیریتی | برچسب DEMO_SYNTHETIC، نتیجهٔ تعارض و رزرو، و پنجرهٔ ۲۴ و ۷۲ ساعت از بانک مرجع خوانده شوند. |
| جریان مسئولیت | پروندهٔ S000013 از ثبت کارشناس تا بستن، با همهٔ نقش‌ها و نسخه‌های متوالی. عامل نامجاز و نسخهٔ کهنه رد شوند. |
| تصمیم با شواهد ناقص | پروندهٔ S000005 قابل تصویب نیست. رد عملیات موجب تغییر نسخه نمی‌شود. |
| رابط | چهار فضای کاری، فارسی راست‌به‌چپ، انگلیسی چپ‌به‌راست، دو پوسته، نمای سناریو و شواهد و بدون خطای جاوااسکریپت. |
| بازگشت نسخه | مجموعهٔ رگرسیون دمو در هر دو اندازهٔ دسکتاپ و موبایل، همراه با آزمون‌های موجود صفحهٔ اصلی. |

در صورت شکست، نخستین گذار یا گزارهٔ ناموفق را با شناسهٔ آزمون و خروجی ثبت کنید. اصلاح را در مالک همان مؤلفه انجام دهید، آزمون انتخابی را تکرار کنید و سپس کل مجموعه را برای نسخهٔ یکپارچه اجرا کنید. تأیید UAT در این پوشه مربوط به اجرای ماشینی معیارهای دموست. پذیرش انسانی و عملیاتی باید با شاهد مستقل ثبت شود.
