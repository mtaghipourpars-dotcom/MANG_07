در بررسی تکمیلی R5، پاسخ HTTP رابطهٔ سناریوی آموزشی `S000013` برای گزینه‌های هم‌گروه و ردیف‌های اثر بررسی شد. شناسه چالش در گزینه‌ها یکسان بود. اثر مستقیم و جانبی از هم متمایز بودند. ردیف منشأ از API جزئیات همان سناریو قابل بازیابی بود و شناسه سفارش واقعی به صورت `null` برگشت.

دستور بازتولید از ریشه مخزن، با وابستگی‌های آزمون و Chromium نصب‌شده:

```sh
python DEV/local/qa/verify.py
```

اجرای محلی از مسیر بانک‌ها و فضای کار تازه آغاز شد. وابستگی‌های npm در این محیط موجود بودند. مسیر دانلود و نصب وابستگی روی ماشین پاک در این اجرا مشاهده نشد. پذیرش انسانی `NOT_RUN` است. هویت و اختیار سازمانی، SAP، تأیید مالی مستقل و اشتراک سبد بین نشست‌های مستقل طبق ماتریس باز هستند.
