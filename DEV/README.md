# ساخت و بازبینی دموی جامع PVPT

نقطه ورود ماشین [AI-STUDIO.md](AI-STUDIO.md) است. [technical-spec.json](technical-spec.json) وابستگی مراحل و معیارهای قابل بررسی را تعریف می‌کند. [ARCHITECTURE.md](ARCHITECTURE.md) مرز رابط، سرور، موتور و داده را مشخص می‌کند.

## اجرای محلی یک‌دستوری (`R21`)

پیش‌نیازها از ریشه مخزن: **Node.js >= 22.13** و **Python >= 3.10** (تنها برای ساخت اولیه بانک سناریو از شواهد مخزن). تنظیمات نمونه در `.env.example` شامل `PORT=3000`، `PVPT_DATABASE_PATH=.pvpt/demo.sqlite` و `PVPT_TOTAL_DEMO_DB=.pvpt/total-demo.sqlite` است (`DATABASE_URL` در معماری دو SQLite منسوخ شده و وارد مسیر اجرا نمی‌شود).

```sh
npm run start:local
```

رفتار دستور `npm run start:local` (فایل `scripts/start-local.mjs`):
- **اجرای نخست (بدون بانک قبلی):** در صورت نبود `node_modules` وابستگی‌ها را نصب می‌کند، وجود Python 3.10+ را بررسی کرده و بانک نسخه‌دار `.pvpt/total-demo.sqlite` را با `scenario-lab/build_bank.py` از شواهد موجود مخزن می‌سازد، صحت `DEMO_SYNTHETIC` و شمار `43200` سناریو را تأیید می‌کند و سپس سرور را روی `http://127.0.0.1:3000` (صفحه اصلی `/` و دموی جامع `/demo/total-system/`) بالا می‌آورد.
- **اجراهای بعدی:** هر دو بانک موجود `.pvpt/total-demo.sqlite` و `.pvpt/demo.sqlite` را بدون بازسازی مخرب بازخوانی می‌کند تا پرونده‌ها، رزروها و درس‌آموخته‌های ثبت‌شده پس از توقف و شروع مجدد حفظ شوند.
- **رفتار خطای شفاف (بدون ساخت داده جایگزین):**
  - نبود یا نسخه قدیمی Python هنگام نیاز به ساخت اولیه: توقف با کد خروج `1` و پیام `[PVPT:PYTHON_REQUIRED]`.
  - خراب یا نامعتبر بودن فایل بانک سناریو: توقف با کد خروج `1` و پیام `[PVPT:INVALID_SCENARIO_BANK]` (هیچ داده جایگزینی ساخته نمی‌شود).
- برای اجرای فقط پیش‌بررسی بدون راه‌اندازی سرور می‌توان `node scripts/start-local.mjs --check-only` اجرا کرد.

برای اجرای دستی گام‌به‌گام نیز همان مسیر زیر برقرار است:

```sh
npm install
node DEV/validate-spec.mjs
python3 scenario-lab/build_bank.py --db .pvpt/total-demo.sqlite
PVPT_TOTAL_DEMO_DB="$PWD/.pvpt/total-demo.sqlite" npm start
```

دمو از مسیر `/demo/total-system/` و صفحه اصلی از `/` باز می‌شود. بانک سناریو از نسخه ثبت‌شده شواهد آموزشی بازسازی می‌شود. داده‌های مرجع برنامه قدیمی و فضای کاری نشست در بانک تنظیم‌شده با `PVPT_DATABASE_PATH` قرار دارند.

## چرخهٔ اجرای ماشینی

اعتبارسنجی قرارداد، آزمون موتور، آزمون API و مرورگر و ثبت شاهد را به ترتیب وابستگی اجرا کنید. هنگام خطا به مرحله مالک برگردید و آزمون‌های همان مرحله و همه مراحل وابسته را تکرار کنید. گردش GitHub Actions در شاخه دمو بانک را می‌سازد و گزارش اجرای مرورگر را در آثار همان کامیت نگه می‌دارد. پذیرش کاربر با مشاهده انسانی و ثبت شناسه اجرا جداگانه انجام می‌شود.

## منشأ داده و مرز اجرا

کاتالوگ عمومی، خانواده و مدل محصول را تأیید می‌کند. داده‌های پرونده، هزینه، وصول، ظرفیت و شواهد اجرای موجود در بانک سناریو با طبقهٔ `DEMO_SYNTHETIC` عرضه می‌شوند. ردیف‌های تاریخی فقط به‌عنوان مرجع سناریو شناخته می‌شوند. برای محاسبهٔ مورد تأیید شرکت، منبع عملیاتی دارای صاحب داده، تاریخ برش، شناسه سند، نگاشت اردر/WBS و تأیید مالی لازم است. در ورودی‌های نسخهٔ حاضر این زنجیره احراز نشده است.
